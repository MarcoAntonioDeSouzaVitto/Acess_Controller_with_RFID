# Sistema de controle e gestão de acessos
&emsp;Liguagens ultilizadas no projeto - Python, C++, JavaScript, SQL, HTML e CSS

### O que foi desenvolvido

&emsp; O objetivo do projeto foi criar um sistema de controle de acesso com tags.No projeto foi ultilizado um identificador por radiofrequência (RFID) que possibilitou identificar as tags e conceder ou restringir o acesso conforme seu registro no sistema. Paralelamente, foi desenvolvido um aplicativo, que permite a liberação do acesso pelo smartphone Android no sistema, exclusivamente para aqueles que estão cadastrados. E ao final de cada tentativa de acesso são registrados data, hora e status da solicitação de acesso.
